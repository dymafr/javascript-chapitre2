# Projet JavaScript du chapitre 2

Ce dépôt contient le projet minimal construit dans la leçon
« Installation et configuration de Vite ».

Prérequis : une version de Node.js compatible avec Vite 8
(`^20.19.0 || >=22.12.0`). Utilisez de préférence une version LTS maintenue.

Installez les dépendances :

```bash
npm install
```

Lancez le serveur de développement :

```bash
npm run dev
```

Créez le build de production :

```bash
npm run build
```

Prévisualisez localement le build :

```bash
npm run preview
```

Vérifiez la syntaxe du fichier JavaScript :

```bash
npm test
```
